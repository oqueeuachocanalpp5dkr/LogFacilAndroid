LOG FÁCIL — PROJETO ANDROID

Este é o projeto-fonte Android Studio do Log Fácil. O ambiente disponível nesta sessão não possui Android SDK/Gradle instalados para compilar e assinar um APK pronto.

COMO GERAR O APK:
1. Instale o Android Studio em um computador.
2. Extraia a pasta LogFacilAndroid.
3. Abra essa pasta no Android Studio.
4. Aguarde o Gradle sincronizar e instalar os componentes solicitados (SDK 35).
5. Use Build > Build APK(s).
6. O APK de depuração será criado em app/build/outputs/apk/debug/app-debug.apk.

O app carrega o HTML local incluído em app/src/main/assets/index.html e funciona sem internet.
Antes de usar em operação real, teste a gravação e a exportação ADIF no seu aparelho e mantenha backups dos logs.
A importação no QRZ é feita manualmente pelo site; este app não envia dados automaticamente ao QRZ.
